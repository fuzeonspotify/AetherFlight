# AetherFlight Fresh Procedural World Reset

This workflow replaces the active Unreal Landscape setup in the open level with
one clean procedural terrain generated by `AProceduralWorldDirector`, then
rebuilds the data-driven procedural biomes on top of it.

## What the reset removes

The reset deletes every **loaded** actor matching these terrain classes:

- Landscape
- Landscape Proxy
- Landscape Streaming Proxy
- Landscape spline/gizmo/mesh-proxy actors
- Landscape placeholders
- Existing `AProceduralWorldDirector` actors
- Existing `AProceduralBiomeDirector` actors

The reset does not delete the aircraft, flight pawn, game mode, weather code,
materials, imported Static Mesh assets, or source heightmap/weightmap files.
Those unused assets can remain without affecting the fresh world.

## What the reset creates

- One always-loaded actor named **Aether Fresh Procedural World**
- Deterministic world seed `1847`
- A 48 km procedural terrain
- 8 terrain tiles per axis
- 129 vertices per tile axis
- Procedural collision for flying/landing
- The existing ocean, runway, atmosphere, weather, spawn, and turbulence systems
- Zero legacy hardcoded forest/rock instances
- One rebuilt **Aether Procedural Biomes** actor using discovered vegetation and
  rock Static Mesh assets

## Run it

1. Stop Play In Editor.
2. Open `/Game/Maps/AetherWorld`.
3. Open **Window > World Partition > World Partition Editor**.
4. Select the complete old terrain region, right-click, and choose
   **Load Selected Cells**. The Unreal editor actor subsystem can only delete
   actors currently loaded into the editor.
5. Choose **Tools > Execute Python Script**.
6. Run:

   `Content/Python/ResetFreshProceduralWorld.py`

7. Click **Yes** in the destructive reset confirmation.
8. Let the terrain and biome generation finish. The biome installer saves the
   current level automatically.

## Expected Outliner result

The old Landscape, Landscape2, Landscape Streaming Proxies, and previous biome
or world directors should be gone. The main generated actors should be:

- **Aether Fresh Procedural World**
- **Aether Procedural Biomes**

## Safety checks

The script stops before generation when:

- Play In Editor is running
- the compiled procedural world actor is unavailable
- one or more loaded Landscape actors could not be deleted
- the biome installer is missing

After deletion, it scans the loaded actors again and refuses to continue if any
loaded Landscape actor remains. If it reports remaining or missing terrain
proxies, load the full World Partition terrain region and rerun the reset.

## Re-running

The reset is intentionally repeatable. Running it again deletes the generated
world and biome directors, then creates a new deterministic world from scratch.
