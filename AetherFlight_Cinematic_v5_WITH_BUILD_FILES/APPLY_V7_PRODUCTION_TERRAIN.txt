AETHER FLIGHT v7 - PRODUCTION LANDSCAPE UPGRADE
================================================

This update does not delete your working aircraft, flight model, HUD, controls,
weather, runway, imported drone assets, or saved Unreal content.

SAFE IN-PLACE UPDATE
--------------------
1. Close Unreal Editor.
2. Back up your current AetherFlight folder.
3. Extract the patch ZIP directly into that AetherFlight folder.
4. Allow Windows to replace files with matching names.
5. Run BUILD_ME_FIRST.cmd from the project root.
6. Open AetherFlight.uproject.
7. Follow PRODUCTION_LANDSCAPE_SETUP.md exactly.

WHAT THIS PATCH ADDS
--------------------
- 4033 x 4033, 16-bit eroded Landscape heightmap for a 48 km world.
- Grass, rock, scree, and snow weightmaps.
- Tileable PBR surface textures and macro variation.
- Unreal Python material/texture installer.
- Landscape-aware runtime terrain and foliage placement.
- Water Body detection, Water plugin, and PCG plugin support.
- Fixed Virtual Shadow Map setting in the config file Unreal actually loads.

ROLLBACK
--------
The old procedural terrain is still present as a fallback. If AetherWorld is
not open or its Landscape is removed, the game generates the previous terrain
instead. You can also restore your backed-up folder. No existing .uasset is
deleted by this patch.

EXPECTED OUTPUT AFTER IMPORT
----------------------------
[Aether] Production Landscape detected; runtime placeholder terrain is disabled.

If you see the fallback warning, press Play with AetherWorld open and verify a
Landscape actor exists in the World Outliner.
